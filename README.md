## 📋 Sobre o Projeto

Site desenvolvido para a **Briggy — Vício em Brigadeiro**, uma brigaderia artesanal. O design usa a identidade visual da marca (rosa + marrom chocolate) para criar uma experiência apetitosa e convidativa.

## ✨ Funcionalidades

- 🎨 Design com identidade visual forte (rosa + chocolate)
- 📋 Cardápio digital interativo com sabores
- 📱 Layout totalmente responsivo
- 🛒 Integração com WhatsApp para pedidos
- 📍 Informações de contato e localização
- ✨ Animações e efeitos visuais
